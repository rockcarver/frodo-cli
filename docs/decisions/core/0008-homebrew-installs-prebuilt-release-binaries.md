# Homebrew installs prebuilt release binaries

Recorded in the umbrella repository rockcarver/frodo (archived 2026-10) until 2026-10-24; this copy is the record.

## Context and problem statement

The tap's formulas used to build the CLI from source on the user's machine, which needed Node.js and produced an untested second binary.

## Decision

- Formulas install the release zip for the user's OS and CPU, pinned by sha256. That is the binary CI tested, signed and notarized.
- The formulas `frodo-cli` (stable) and `frodo-cli-next` (prerelease) are generated by the CLI repository's `tools/update-homebrew-formula.mjs` and committed to the tap only by the CLI pipeline job that updates the formulas. A prerelease touches only the `next` formula.
- Nobody edits `Formula/*.rb` by hand.

## Consequences

- A hand edit is overwritten by the next release.
- At the time of recording, the stable formula still builds a 4.x release from source; the next stable release regenerates it as a prebuilt install.
- The tap has no automation of its own.
